# v5.6.1

Activity lookups now show complete lists through private page controls and automatic downloads. `/role_activity` separates every current role member into active and inactive lists; the CSV uses explicit `active` and `inactive` status values. Inactive means no matching recorded events during the selected period. Optional logs include every matching saved event. Other activity, member, daily, linked-account and inactivity reports also include every matching entry.

Member reports fetch the entire Discord roster and include accounts with no saved activity. Inactivity lookups use the requested threshold and platform, including members inactive for 30–89 days. Unknown last activity is labelled explicitly. Rolling date windows retain the oldest partial calendar day. Large attachments are compressed or split into complete records, with every file accessible from the report pages.

Replace the previous bridge wheel with `endstone_discord_bridge-5.6.1-py3-none-any.whl` and restart the bridge. Existing configuration and saved activity remain compatible. Complete roster lookups require Server Members Intent.

Validation: 65 local tests pass on Python 3.11 with Endstone 0.11.15 and discord.py 2.7.1. A command test fetches 260 role members, verifies both complete 130-member groups and the CSV, and visits every result page. No live Discord command was sent during this verification.
